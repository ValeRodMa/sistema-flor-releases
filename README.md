## [ENG]

This repository hosts the **official installers** of **SGPPM**, a desktop
patient-management system for medical practices: clinical records, imaging
studies, audiograms and email intake — everything encrypted and stored locally
on the practice's computer. Built with Electron by [vrmlabs.dev](https://vrmlabs.dev).

- **What's here:** compiled Windows installers only (`Instalador-SGPPM-X.Y.Z.exe`), published under [Releases](../../releases). No source code — the codebase lives in a private repository.
- **Why it's public:** installed copies of SGPPM check this repository for **automatic updates** and download new versions in the background.
- **Can I just install it?** The installer runs, but on first launch the app asks for a **product activation key**. Keys are issued per purchase and bind to one computer; without one the app cannot be used.
- **Windows SmartScreen** may show a warning ("More info" → "Run anyway"): expected, since the installer is distributed through a private channel and not commercially signed.

## [SPA]

Este repositorio aloja los **instaladores oficiales** de **SGPPM**, un sistema
de escritorio de gestión de pacientes para consultorios médicos: historia
clínica, estudios con sus archivos, audiogramas y recepción por correo — todo
cifrado y guardado localmente en la computadora del consultorio. Hecho con
Electron por [vrmlabs.dev](https://vrmlabs.dev).

- **Qué hay acá:** solo instaladores de Windows compilados (`Instalador-SGPPM-X.Y.Z.exe`), publicados en [Releases](../../releases). Nada de código — el código vive en un repositorio privado.
- **Por qué es público:** las copias instaladas de SGPPM consultan este repositorio para las **actualizaciones automáticas** y descargan las versiones nuevas en segundo plano.
- **¿Puedo instalarlo sin más?** El instalador corre, pero en el primer arranque el programa pide una **clave de activación**. Las claves se emiten por compra y quedan atadas a una computadora; sin clave el programa no se puede usar.
- **Windows SmartScreen** puede mostrar el aviso azul ("Más información" → "Ejecutar de todas formas"): es lo esperado, porque el instalador se distribuye por canal privado y no está firmado comercialmente.

**Compra, licencias y soporte:** valentin.rodriguez@vrmlabs.dev
